CRITICAL HEADLINE FORMATTING FIXES:

**MOST COMMON ERRORS TO AVOID:**

1. **Sports Events**: ALWAYS use "Team A vs Team B" or "Team A v Team B" format (not "Team A v Team B")
2. **Years**: For events, put year AFTER event name: "Event Name YEAR" not "YEAR Event Name"  
3. **Court Cases**: Use format "State v Defendant" or "People v Defendant" NOT "CA v Defendant"
4. **TV Shows**: Season/Episode format is S[#], E[#] - use actual episode numbers, not dates
5. **Action Words**: Use concise action words: "Match", "Game", "Performance", "Premiere" (not "Game Action" or "Performance Onstage")
6. **Remove Extra Words**: Remove words like "During", "Onstage", "Attendance", "Appearance" - just use the core action
7. **Last Names Only**: Use only last names unless first name is critical for identification

**SPECIFIC FORMAT EXAMPLES:**
- Sports: "Lakers vs Celtics 2025, Bryant, Game" NOT "Lakers v Celtics, Bryant, Game Action"

- Court: "State v Kohberger, Criminal, Sentencing" NOT "CA v Kohberger, Criminal, Sentencing"
- TV: "Love Island USA, S7, E22, Smith, Jones" NOT "Love Island USA, S7, E722, Smith, Jones"
- Premieres: "Movie Title, 2025, Smith, Premiere" NOT "Movie Title, Smith, Premiere Attendance"

FINAL REFINED FORMAT RULES FOR DAMZ HEADLINES
These instructions are based on real-world corrections to ensure 100% accuracy when revising headlines.

1) Headline - General
Format:
[Main Subject(s) Last Name(s)], [Key Topic]

Example:
Wilson, Killer Mike, New Song Called Superman
Example:
Osbourne, Wilson, Engagement
Example:
Bradley, Amy and her Brother Brad

Key Refinements
- Switched from full descriptions to just key names & topics.
- Removed unnecessary words like "talks about" or "discusses".
- List key people first (separated by commas) and then the topic.
- Prioritize famous people names listed first, not alphabetized unless unknown then alphabetize.
- Topic should be extremely concise—just keywords.
- Show or stage name is one name; don't split into first and last name.

2) Headline - Commercial
Format:
[Main Subject(s) Last Name(s)], [Company or Brand Name], [Campaign Name OR General Topic], COMM

Example:
Affleck, Dunkin, Dunkings, COMM

Key Refinements
- Switched from "Ben Affleck Dunkin Commercial" to a structured order.
- Only last name for the celebrity.
- Campaign name or relevant keyword should be included (e.g., "Dunkings").
- "COMM" should always be at the end.

3) Headline - Court
Format:
[Case Name], [Court Type], [Key Event]

Example:
CA v Rakim Mayers, Criminal, Verdict Reached

Key Refinements
- Revised case naming to "CA v. [Defendant]" instead of full legal case name.
- Court type should be included (e.g., Criminal, Civil, Appeals).
- "Verdict Reached" is the correct phrasing for case outcomes.
- Include more concise detail in case outcomes after court type.

4) Headline - Government
Format:
[Main Subject(s) Last Name(s)], [Government Agency OR Event], [Main Topic]

Example:
Trump, Musk, White House, Signing Executive Orders In Oval Office

Key Refinements
- "White House" instead of "Oval Office" as the main entity.
- No need for "joins" or extra context—just last names and topic.
- Topic should be action-driven (e.g., "Signing Executive Orders").

5) Headline - Movie Clip
Format:
[Movie Title], [Release Year], [Film Type: TRAILER, BTS, FFILM]

Example:
Beetlejuice, 1988, FFILM
Example:
Superman, 2025, TRAILER
Example:
Highest 2 Lowest, 2025, TRAILER

Key Refinements
- Actors’ last names are allowed—only the main two; if more than two, add "And Others".
- No scene name.
- No need for "Studio Publicity Still"—this is implied.
- All caps for film type [Film Type: TRAILER, BTS, FFILM].
- BTS is for behind the scenes.
- FFILM is feature film.

6) Headline - Music Video
Format:
[Last Name(s) OR Band Name], [Song Title], MXV

Example:
Carpenter, Please Please Please, MXV

Key Refinements
- Specify "Music Video" using abbreviation MXV.
- Artist’s last name or band name first.

7) Headline - Police Images
Format:
[Police Department OR Main Subject], [Main Event or Action]

Example:
NYPD, Arrest of Pro-Palestinian Protesters

Key Refinements
- "NYPD" instead of "New York Police" (shorter & clearer).
- "Arrest of Protesters" instead of vague phrasing.
- Focus on action, not location or context.

8) Headline - Presser
Format:
[Main Subject(s) Last Name(s)], [Organizing Agency], [Main Topic], PRESSER

Example:
Trump, Starmer, White House, Peace Deal for Ukraine, PRESSER
Example:

- Entity second (e.g., "White House").
- Speakers listed by last name, only two main; if more, list "And Others".
- Concise topic statement—no extra words.

Print Type Descriptions:
POSTER - picture for print, used for advertisement on walls, events, or rooms.
PROMO - promotional materials used to advertise a product, event, or service.
PLAYBILL - program given to audiences at theater performance.
SKETCH - quickly drawn visual or preliminary drawing.
DOC - contracts, certificates, reports, legal filings, official notices.
ALBUM - cover art for album.
SONG - cover art for song.
BOOK - cover for a book or manual.

Key Refinements
- Song and Album type should have single quotation marks around the title.
- Type should be in AP style for consistency.
