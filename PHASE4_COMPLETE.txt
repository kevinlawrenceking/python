WHAT HAPPENS NOW (Production Behavior)
================================================================================

When summarize_document_event.py processes a document:

1. AI generates summary with story fields (headline, subhead, body, etc.)
   
2. save_structured_summary() called with enable_articles=True
   
3. Documents table updated (LEGACY - existing code still works)
   - summary_ai, summary_ai_html
   - story_headline, story_subhead, story_body, etc.
   
4. Articles table updated (NEW - Phase 4 feature)
   - Queries document metadata (fk_case, fk_case_event, event_date)
   - Calls upsert_article_for_event() stored procedure
   - Finds today's Pending article OR creates new one
   - Updates content, increments version, links event
   - Returns article GUID
   
5. Both systems running in parallel during transition period
